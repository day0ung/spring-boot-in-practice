# 6.4 스프링의 프록시 팩토리 빈

## ProxyFactoryBean

- 스프링이 제공하는 프록시 생성 전용 팩토리 빈
- `TxProxyFactoryBean`을 직접 만들 필요 없이 스프링이 제공하는 기반 클래스 활용

```java
@Test
public void proxyFactoryBean() {
    ProxyFactoryBean pfBean = new ProxyFactoryBean();
    pfBean.setTarget(new HelloTarget()); // 타깃 설정
    pfBean.addAdvice(new UppercaseAdvice()); // 부가 기능(어드바이스) 추가

    Hello proxiedHello = (Hello) pfBean.getObject();
    assertThat(proxiedHello.sayHello("Toby"), is("HELLO TOBY"));
}
```

## 어드바이스 (Advice)

- 타깃 오브젝트에 적용하는 **부가 기능**을 담은 오브젝트
- 타깃에 종속되지 않는 순수한 부가 기능만 담음

```java
public class UppercaseAdvice implements MethodInterceptor {
    public Object invoke(MethodInvocation invocation) throws Throwable {
        String ret = (String) invocation.proceed(); // 타깃 메서드 호출
        return ret.toUpperCase(); // 부가 기능
    }
}
```

- `MethodInterceptor`: `InvocationHandler`와 달리 타깃 오브젝트를 직접 알지 못함
- `invocation.proceed()`로 타깃 메서드를 호출 → 타깃 정보를 갖는 `MethodInvocation`이 처리

## 포인트컷 (Pointcut)

- 어드바이스를 **어느 메서드에 적용할지** 결정하는 오브젝트

```java
ProxyFactoryBean pfBean = new ProxyFactoryBean();
pfBean.setTarget(new HelloTarget());

// 포인트컷: sayH로 시작하는 메서드에만 적용
NameMatchMethodPointcut pointcut = new NameMatchMethodPointcut();
pointcut.setMappedName("sayH*");

// 어드바이저 = 포인트컷 + 어드바이스
pfBean.addAdvisor(new DefaultPointcutAdvisor(pointcut, new UppercaseAdvice()));

Hello proxiedHello = (Hello) pfBean.getObject();
assertThat(proxiedHello.sayHello("Toby"), is("HELLO TOBY"));
assertThat(proxiedHello.sayThankYou("Toby"), is("Thank You Toby")); // 적용 안 됨
```

## 어드바이저 (Advisor)

- **포인트컷 + 어드바이스** 의 조합
- 어디에(포인트컷) 무엇을(어드바이스) 적용할지를 함께 관리

```
어드바이저 = 포인트컷(메서드 선정) + 어드바이스(부가 기능)
```

## ProxyFactoryBean 적용

```xml
<bean id="userService" class="org.springframework.aop.framework.ProxyFactoryBean">
    <property name="target" ref="userServiceImpl" />
    <property name="interceptorNames">
        <list>
            <value>transactionAdvisor</value>
        </list>
    </property>
</bean>

<bean id="transactionAdvisor"
      class="org.springframework.aop.support.DefaultPointcutAdvisor">
    <property name="advice" ref="transactionAdvice" />
    <property name="pointcut" ref="transactionPointcut" />
</bean>

<bean id="transactionAdvice" class="...TransactionAdvice">
    <property name="transactionManager" ref="transactionManager" />
</bean>

<bean id="transactionPointcut"
      class="org.springframework.aop.support.NameMatchMethodPointcut">
    <property name="mappedName" value="upgrade*" />
</bean>
```

## 직접 만든 팩토리 빈 vs ProxyFactoryBean 비교

| 항목 | TxProxyFactoryBean | ProxyFactoryBean |
|---|---|---|
| 부가 기능 재사용 | 타깃마다 별도 설정 | 어드바이스/포인트컷 빈으로 재사용 |
| 메서드 선정 | 직접 구현 | 포인트컷으로 분리 |
| 타깃 의존성 | 있음 | 없음 |

## 정리

> 스프링의 `ProxyFactoryBean`은 어드바이스(부가 기능)와 포인트컷(메서드 선정)을 분리하여  
> 독립적으로 재사용할 수 있게 한다. 이것이 스프링 AOP 구현의 핵심 기반이다.
