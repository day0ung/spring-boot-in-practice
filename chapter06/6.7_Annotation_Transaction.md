# 6.7 애노테이션 트랜잭션 속성과 포인트컷

## @Transactional

- 메서드, 클래스, 인터페이스에 부여할 수 있는 트랜잭션 속성 애노테이션
- 포인트컷과 트랜잭션 속성을 코드에 직접 명시

```java
@Transactional
public class UserServiceImpl implements UserService {

    @Transactional(readOnly = true)
    public User get(String id) { ... }

    @Transactional(readOnly = true)
    public List<User> getAll() { ... }

    public void upgradeLevels() { ... } // 클래스 레벨 @Transactional 적용
}
```

## 트랜잭션 속성 적용 우선순위

1. 메서드에 붙은 `@Transactional`
2. 클래스에 붙은 `@Transactional`
3. 인터페이스 메서드에 붙은 `@Transactional`
4. 인터페이스에 붙은 `@Transactional`

- **가장 가까운 곳**에 있는 속성이 우선 적용됨

```java
@Transactional // 4순위: 인터페이스 레벨
public interface UserService {
    @Transactional(readOnly = true) // 3순위: 인터페이스 메서드 레벨
    User get(String id);
}

@Transactional // 2순위: 클래스 레벨
public class UserServiceImpl implements UserService {
    @Transactional(readOnly = true) // 1순위: 메서드 레벨 → 최우선 적용
    public User get(String id) { ... }
}
```

## @Transactional 속성

```java
@Transactional(
    propagation = Propagation.REQUIRED,       // 전파 속성
    isolation = Isolation.DEFAULT,            // 격리 수준
    timeout = 30,                             // 타임아웃(초)
    readOnly = false,                         // 읽기 전용
    rollbackFor = {Exception.class},          // 이 예외 발생 시 롤백
    noRollbackFor = {RuntimeException.class}  // 이 예외 발생 시 롤백 안 함
)
public void someMethod() { ... }
```

## 트랜잭션 애노테이션 활성화 설정

```xml
<!-- XML 설정 -->
<tx:annotation-driven transaction-manager="transactionManager" />
```

```java
// 자바 설정
@Configuration
@EnableTransactionManagement
public class AppConfig { ... }
```

## @Transactional vs XML 트랜잭션 설정 비교

| 항목 | @Transactional | XML 설정 |
|---|---|---|
| 설정 위치 | 코드 내부 | 설정 파일 |
| 가독성 | 직관적 | 분리되어 한 눈에 보기 어려움 |
| 변경 | 재컴파일 필요 | 재컴파일 불필요 |
| 관리 | 분산됨 | 한 곳에서 관리 |
| 권장 | 대부분의 경우 | 일괄 설정이 필요할 때 |

## 포인트컷과 결합

- `@Transactional`이 붙은 메서드를 자동으로 포인트컷이 선정
- 별도 포인트컷 설정 불필요

```java
// 이것만으로 트랜잭션 적용 완료
@Transactional
public void upgradeLevels() {
    // 비즈니스 로직만
}
```

## 정리

> `@Transactional`은 트랜잭션 속성을 코드에 직접 명시하여 직관적이고 간결하게  
> 트랜잭션을 적용할 수 있다. 클래스/메서드 레벨의 우선순위를 활용하면  
> 공통 속성은 클래스에, 예외적인 속성은 메서드에 지정할 수 있다.
