# 6.5 스프링 AOP

## 자동 프록시 생성

- `ProxyFactoryBean`을 쓰더라도 타깃 빈 수만큼 설정이 반복됨
- **빈 후처리기(BeanPostProcessor)** 를 사용해 빈 자동 프록시 생성

### DefaultAdvisorAutoProxyCreator

- 스프링이 제공하는 빈 후처리기
- 등록된 모든 어드바이저를 참조하여 조건에 맞는 빈에 자동으로 프록시 적용

```xml
<!-- 빈 후처리기 등록 -->
<bean class="org.springframework.aop.framework.autoproxy.DefaultAdvisorAutoProxyCreator" />

<!-- 어드바이저 등록 -->
<bean id="transactionAdvisor"
      class="org.springframework.aop.support.DefaultPointcutAdvisor">
    <property name="advice" ref="transactionAdvice" />
    <property name="pointcut" ref="transactionPointcut" />
</bean>
```

- `userService` 빈 설정에서 프록시 관련 설정을 제거하고 순수한 타깃 클래스만 등록하면 됨

## 포인트컷 표현식

- `NameMatchMethodPointcut`은 메서드 이름만 선정 가능
- **AspectJ 포인트컷 표현식**을 사용하면 클래스와 메서드를 더 정밀하게 선정 가능

```xml
<bean id="transactionPointcut"
      class="org.springframework.aop.aspectj.AspectJExpressionPointcut">
    <property name="expression" value="execution(* *..*ServiceImpl.upgrade*(..))" />
</bean>
```

### 포인트컷 표현식 문법

```
execution([접근제한자] 리턴타입 [클래스타입.]메서드이름(파라미터) [예외])
```

```
execution(* springbook.service.*Service.*(..))
│          │  │                  │         │
│          │  패키지              메서드명    파라미터
│          리턴타입
접근제한자 생략(모두)
```

| 표현식 예시 | 설명 |
|---|---|
| `execution(* *(..))` | 모든 메서드 |
| `execution(* hello(..))` | 이름이 hello인 모든 메서드 |
| `execution(* springbook..*.*(..))` | springbook 패키지 하위 모든 메서드 |
| `execution(* *..ServiceImpl.upgrade*(..))` | ServiceImpl로 끝나는 클래스의 upgrade로 시작하는 메서드 |

## AOP란?

- **Aspect Oriented Programming** (관점 지향 프로그래밍)
- 핵심 기능(비즈니스 로직)과 부가 기능(트랜잭션, 로깅 등)을 분리하여 모듈화

### AOP 주요 용어

| 용어 | 설명 |
|---|---|
| 어드바이스(Advice) | 부가 기능 자체 |
| 포인트컷(Pointcut) | 어드바이스를 적용할 메서드 선정 로직 |
| 어드바이저(Advisor) | 포인트컷 + 어드바이스 |
| 애스펙트(Aspect) | AOP의 기본 모듈. 어드바이저와 동일하거나 더 확장된 개념 |
| 조인포인트(JoinPoint) | 어드바이스가 적용될 수 있는 위치 (스프링에서는 메서드 실행 시점) |
| 위빙(Weaving) | 어드바이스를 타깃에 적용하는 과정 |

### 스프링 AOP의 특징

- **런타임 위빙**: 다이내믹 프록시를 통해 런타임 시점에 부가 기능 적용
- 인터페이스 기반: JDK 다이내믹 프록시 사용 (인터페이스 없으면 CGLIB)
- 컴파일 타임, 클래스 로딩 타임 위빙은 AspectJ 사용

## @AspectJ 애노테이션 AOP

```java
@Aspect
public class TransactionAspect {

    @Pointcut("execution(* *..*ServiceImpl.upgrade*(..))")
    private void serviceOperation() {}

    @Around("serviceOperation()")
    public Object doTransaction(ProceedingJoinPoint pjp) throws Throwable {
        TransactionStatus status =
            transactionManager.getTransaction(new DefaultTransactionDefinition());
        try {
            Object ret = pjp.proceed(); // 타깃 메서드 호출
            transactionManager.commit(status);
            return ret;
        } catch (RuntimeException e) {
            transactionManager.rollback(status);
            throw e;
        }
    }
}
```

## 정리

> 스프링 AOP는 프록시 기반으로 동작하며, 자동 프록시 생성기와 포인트컷 표현식을 통해  
> 설정 없이도 원하는 빈에 부가 기능을 자동으로 적용할 수 있다.
