# 1.8 XML을 이용한 설정

## XML 설정

- `@Configuration` 자바 클래스 대신 XML 파일로 빈 설정정보를 작성할 수 있음
- 컴파일 없이 설정 변경이 가능하고, 스프링 초기부터 폭넓게 사용된 방식

### 자바 코드 설정 vs XML 설정 비교

| 항목 | 자바 코드(`@Configuration`) | XML |
|---|---|---|
| 빈 설정 | `@Bean` 메서드 | `<bean>` 태그 |
| 빈 이름 | 메서드 이름 | `id` 속성 |
| 빈 클래스 | 리턴 타입 | `class` 속성 |
| 의존관계 주입 | 생성자/수정자 호출 | `<constructor-arg>` / `<property>` |

### connectionMaker 전환

```java
// 자바 코드
@Bean
public ConnectionMaker connectionMaker() {
    return new DConnectionMaker();
}
```

```xml
<!-- XML -->
<bean id="connectionMaker" class="springbook.user.dao.DConnectionMaker" />
```

### userDao 전환

```java
// 자바 코드
@Bean
public UserDao userDao() {
    UserDao userDao = new UserDao();
    userDao.setConnectionMaker(connectionMaker());
    return userDao;
}
```

```xml
<!-- XML -->
<bean id="userDao" class="springbook.user.dao.UserDao">
    <property name="connectionMaker" ref="connectionMaker" />
</bean>
```

- `name`: 수정자 메서드의 프로퍼티 이름 (`setConnectionMaker` → `connectionMaker`)
- `ref`: 주입할 빈의 `id`

### 전체 XML 설정 파일

```xml
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
                           http://www.springframework.org/schema/beans/spring-beans.xsd">

    <bean id="connectionMaker" class="springbook.user.dao.DConnectionMaker" />

    <bean id="userDao" class="springbook.user.dao.UserDao">
        <property name="connectionMaker" ref="connectionMaker" />
    </bean>

</beans>
```

## XML을 이용하는 애플리케이션 컨텍스트

- XML 설정 파일을 사용할 때는 `GenericXmlApplicationContext` 사용

```java
ApplicationContext context =
    new GenericXmlApplicationContext("applicationContext.xml");
```

- 클래스패스 루트에 XML 파일을 두면 파일명만으로 로드 가능

## DataSource 인터페이스로 변환

### DataSource 인터페이스 적용

- `ConnectionMaker`는 직접 만든 인터페이스지만, 사실 자바에는 DB 커넥션을 관리하는
  `DataSource` 인터페이스가 이미 존재
- 스프링이 제공하는 `SimpleDriverDataSource` 등을 활용하면 `ConnectionMaker`를 대체 가능

```java
public class UserDao {
    private DataSource dataSource;

    public void setDataSource(DataSource dataSource) {
        this.dataSource = dataSource;
    }

    public void add(User user) throws SQLException {
        Connection c = dataSource.getConnection();
        // ...
    }
}
```

### 자바 코드 설정

```java
@Bean
public DataSource dataSource() {
    SimpleDriverDataSource dataSource = new SimpleDriverDataSource();
    dataSource.setDriverClass(com.mysql.jdbc.Driver.class);
    dataSource.setUrl("jdbc:mysql://localhost/springbook");
    dataSource.setUsername("spring");
    dataSource.setPassword("book");
    return dataSource;
}

@Bean
public UserDao userDao() {
    UserDao userDao = new UserDao();
    userDao.setDataSource(dataSource());
    return userDao;
}
```

### XML 설정

```xml
<bean id="dataSource"
      class="org.springframework.jdbc.datasource.SimpleDriverDataSource">
    <property name="driverClass" value="com.mysql.jdbc.Driver" />
    <property name="url" value="jdbc:mysql://localhost/springbook" />
    <property name="username" value="spring" />
    <property name="password" value="book" />
</bean>
```

## 프로퍼티 값의 주입

- `ref`는 다른 빈 오브젝트의 레퍼런스를 주입
- `value`는 단순 값(String, primitive 등)을 주입

```xml
<property name="driverClass" value="com.mysql.jdbc.Driver" />
```

- 스프링은 `value`로 전달된 문자열을 프로퍼티 타입에 맞게 **자동 변환**해줌
  - `"com.mysql.jdbc.Driver"` → `Class` 타입으로 변환
  - `"8080"` → `int` 타입으로 변환

## 정리

> XML 설정은 컴파일 없이 변경 가능하다는 장점이 있으며, `<bean>`, `<property>`, `ref`, `value`
> 를 통해 자바 코드 설정과 동일한 DI 구성을 표현할 수 있다.
